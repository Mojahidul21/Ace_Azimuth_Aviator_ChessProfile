# Portfolio maintenance

- Main content and rating checkpoints: `src/main.jsx`
- Visual styling and responsive behavior: `src/styles.css`
- Update profile metrics and the snapshot date when the source profile changes.
- Keep all performance claims grounded in verified profile/game data. Illustrative visuals should remain clearly labeled.

## Vercel deployment

Import the GitHub repository into Vercel. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`. Install command: `npm install`.
